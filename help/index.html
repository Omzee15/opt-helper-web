Set up the AI launcher

The launcher in OptHelper sends what you type to an AI provider you already have on your Mac. OptHelper doesn't ask you to sign in itself, so the provider has to be installed and logged in in your terminal first.

Seeing this message in the launcher?

Error Processing Response : Help

It means OptHelper couldn't get an answer from the provider, almost always because it isn't installed yet or you haven't logged in. Follow the steps below.

Setup

  1. Install the provider you'd like to use in your terminal

    Please install the provider you'd like to use as a command-line (CLI) tool. For Claude, that's Claude Code:

    npm install -g @anthropic-ai/claude-code

    The install guide at claude.com/claude-code lists other ways to install it.

  2. Log in there

    Open Terminal, start the provider, and finish its login:

    claude

    Follow the prompts to sign in. Once it's logged in, you can quit it. OptHelper uses that same login.

  3. Check it works in your terminal 
    claude -p "say hi"

    If that prints a reply, the provider is ready. If it asks you to log in or shows an error, fix that first: OptHelper can only work when this command works.

  4. Choose it in OptHelper

    Click the OptHelper icon in the menu bar, then pick the Provider and the Model you want. Open the launcher and try a command again.

Using Gemini instead

Choose Gemini as the provider in the menu bar, then use Set Gemini API key… to paste a key from Google AI Studio. Gemini doesn't need a terminal install.

Still stuck?

Make sure the command from step 3 works in Terminal, then quit and reopen OptHelper from the menu bar icon. If it still fails, open an issue on GitHub and include what you see in Terminal.
